# 谍网 SPYNET

冷战谍报对战卡牌 · 微信小游戏

## 独有机制（区别于市面通用卡牌）

| 机制 | 说明 |
|---|---|
| **值班暗号** | 每回合公开「甲/乙/丙」并轮换；打出同频段牌，主效果 +1。卡面有频段角标 |
| **暴露度** | 行动 +2 / 诡计 +1 / 安全屋 -1；高暴露更易被盯上 |
| **深潜** | 不打手牌：暴露清零、抽 2、免疫对方行动。高暴露时的保命/翻盘手段 |
| **蒸发协议** | 弃光抽 5、+2 掩护、清暴露 |
| **命名** | 死信箱 / 静默清除 / 碎纸机 / 深眠 / 饵雷 / 翻转线人 / 镜像人 / 密码本 |

## 模式

| 模式 | 玩法 |
|---|---|
| **密令对决** | 1v1 AI |
| **同屏潜伏** | 两人一机，交替遮挡 |
| **小队行动** | 你 + 搭档 vs 敌方双人，队伍掩护 18 |

## 交互

- 点手牌选中 → 再点收回 → **确认出击**
- **深潜** 按钮 / 情报：监听·干扰·破译
- 设置：音效 / 震动（本地记住）
- 首次启动隐私协议弹窗
